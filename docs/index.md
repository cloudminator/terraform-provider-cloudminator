# Cloudminator Provider

The Cloudminator provider manages resources on the [Cloudminator](https://cloudminator.com)
sovereign cloud platform: projects, SSH keys, object-storage buckets and access keys, VPCs,
subnets, firewall rules, virtual machines and secrets. It works with Terraform and OpenTofu.

## Authentication

Create an API key in the Cloudminator console (*Organization → API keys*) and expose it
to the provider, preferably through the environment:

```shell
export CLOUDMINATOR_ENDPOINT="https://platform.example.com"
export CLOUDMINATOR_API_KEY="cm_…"
export CLOUDMINATOR_ORG="acme"
```

The key acts with the role and scope it was created with; a plan fails with a `403`
for anything outside it.

## Organizations and projects

Every resource belongs to an organization, and most to a project inside it. Set defaults
on the provider (`org`, `project`) and override them per resource with the `org` and
`project` arguments. Changing either on a resource replaces it.

## Identity and import

Buckets are identified by their name. All other resources get a server-assigned id
(for example `vm-…`); their `name` is a mutable display label and need not be unique.
Import ids are `org/project/id` for project-scoped resources and `org/id` for
organization-scoped ones (`cloudminator_project`, `cloudminator_ssh_key`).

## Simulated backends

On non-production platforms some backends may be simulated. Resources and data sources
expose a `simulated` attribute that is `true` when nothing real exists behind them.

## Example Usage

```terraform
terraform {
  required_providers {
    cloudminator = {
      source = "cloudminator/cloudminator"
    }
  }
}

# Credentials are best supplied through the environment:
#   CLOUDMINATOR_ENDPOINT, CLOUDMINATOR_API_KEY, CLOUDMINATOR_ORG, CLOUDMINATOR_PROJECT
provider "cloudminator" {
  endpoint = "https://platform.example.com"
  org      = "acme"
  project  = "default"
}
```

## Schema

### Optional

- `api_key` (String, Sensitive) API key (`cm_…`) used as a bearer token. Create one in the console under *Organization → API keys*. May also be set with `CLOUDMINATOR_API_KEY`.
- `endpoint` (String) Base URL of the Cloudminator platform API, e.g. `https://platform.example.com`. May also be set with the `CLOUDMINATOR_ENDPOINT` environment variable.
- `org` (String) Default organization slug for resources that do not set `org`. May also be set with `CLOUDMINATOR_ORG`.
- `project` (String) Default project slug for project-scoped resources that do not set `project`. May also be set with `CLOUDMINATOR_PROJECT`. Defaults to `default`.
